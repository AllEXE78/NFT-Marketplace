# NFT Marketplace

Одностраничный лендинг, свёрстанный по [макету](https://www.figma.com/design/4vWGnA8EyaQamCEIYOV3qu/NFTMarketplace--Community-?m=auto&t=7eBOdnQlHxwGDoTN-6) из Figma-сообщества.

---

## 🛠 Используемые технологии

- HTML5
- CSS3 (Flexbox, Grid, CSS-переменные, медиазапросы)
- БЭМ-именование
- Git и GitHub Pages

---

## 🎯 Что реализовано

- Адаптивная вёрстка: десктоп, планшет, мобильные устройства (включая брейкпоинты для корректного отображения всех секций).
- Сетки на Flexbox и Grid:
  - шапка,
  - hero-секция с абсолютным позиционированием,
  - карточки (weekly picks),
  - коллаж из двух перекрывающихся картинок,
  - сетка карточек артистов (5 карточек разного размера),
  - секция подписки с коллажем и формой,
  - футер с колонками и иконками соцсетей.
- Кастомные световые эффекты на CSS (псевдоэлементы, blur).
- Интерактив: hover-состояния для ссылок, кнопок, иконок.
- Работа с картинками: `object-fit`, `object-position`, `aspect-ratio` для сохранения пропорций.
- Экспорт графики из Figma (в том числе оригинальных изображений через плагин).
- Шрифты: Playfair Display (Google Fonts, заменён вместо коммерческого Canela), Inter.
- Деплой на GitHub Pages.
